# Combat Spec v0.1

## Pillars

1. Expression over raw DPS.
2. Enemy manipulation: launch, juggle, knockback and eventually bounce/wall bounce.
3. Responsive input through buffering and cancel windows.
4. Style rewards move variety and punishes repetition.

## Current attack graph

Ground:

- Light 01 -> Light 02 -> Light 03
- Heavy -> Launcher
- Dash can cancel the current attack prototype-wide (temporary permissive rule)

Air:

- Light -> Air Light
- Heavy -> Air Heavy downward finisher
