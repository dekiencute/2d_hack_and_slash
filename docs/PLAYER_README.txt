STYLEBREAKER — PRE-ALPHA v0.1.0 — WINDOWS x86_64
See BUILD_STATUS.txt for this candidate's build/test status.

Extract the whole ZIP to a new folder. Run Stylebreaker.exe; Godot/editor
and separate PCK are not needed. Requires Windows x86_64, OpenGL 3.3 GPU.
Native Windows execution remains unverified; executable is unsigned.

Clear five waves. ! STRIKE ! text and yellow tint warn of attacks. Mix
moves to build Style; repetition earns less and taking damage reduces it.

KEYBOARD                         CONTROLLER (Xbox labels)
A / D: Move                      Left stick
Space: Jump / double jump         A / South
Shift: Invulnerable dash          B / East
J: Light combo                    X / West
K: Launcher / air slam            Y / North
Esc: Pause                        Start
R: Restart to title               Back / Select
Enter: Start / retry              A / South on focused button
M: Mute SFX                       F11: Fullscreen

One arena/enemy type, five waves. No music, saves, rebinding, multiplayer
or progression. Attack sheets supply pixel slash effects; health/tint,
hitstop, sound and text provide functional hit/warning feedback. No
separate supplied dash/hit-particle art or app-icon artwork is available.
