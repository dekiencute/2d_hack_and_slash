INSTALLATION
Extract the entire ZIP to a new folder. Run Stylebreaker.exe. Game data is
embedded; no separate PCK, Godot editor or install step is required.
Windows x86_64 and an OpenGL 3.3-compatible GPU are required. The executable
is unsigned. Native Windows execution has NOT been verified by this build.
Do not run from inside the ZIP. Keep README, credits and LICENSES together.

PLAY
Clear five waves in one forest arena. Gold rings and ! STRIKE ! warn of
attacks. Mix moves to build Style; repeating attacks earns less,
and taking damage reduces Style. Victory and defeat offer retry.

KEYBOARD                       CONTROLLER (Xbox-style labels)
A / D  Move                    Left stick
SPACE  Jump / Double jump       A / South
SHIFT  Invulnerable dash        B / East
J      Light combo              X / West
K      Launcher / Aerial slam    Y / North
ESC    Pause / Resume           Start
R      Restart to title         Back / Select
ENTER  Start / Retry            A / South (focused menu button)
M      Mute SFX
F11    Fullscreen

Try: J -> J -> K -> Jump -> J -> J -> K.
Air light hits briefly suspend the player and airborne target.
A dash can cancel an attack. No guns, parries or extra weapons are included.

LIMITATIONS
One arena, one enemy type, five waves. No saves, music, rebinding, online
play or progression. Short existing death/removal behavior is preserved.
Some feedback and UI panels remain placeholders. Pixel camera zoom uses
integer steps; visible area can change when resizing the window.
Controller mappings are checked in software; physical controller, audible
output, GPU performance and native Windows gameplay still need testing.
Automated wave progression is not a human balance playtest.
