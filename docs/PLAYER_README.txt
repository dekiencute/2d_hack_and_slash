STYLEBREAKER PROTOTYPE — PRE-ALPHA 0.1.0 (15 October 2026)

Extract the whole ZIP, then open Stylebreaker.exe. The game data is embedded;
there is no separate PCK to copy. Windows x86_64; OpenGL 3.3-compatible GPU.
This candidate is unsigned. See BUILD_STATUS.txt for verification limits.

Clear five waves of sentinels. Gold rings and ! STRIKE ! warn of an attack.
Only two enemies can wind up a strike at once. Mix moves to raise Style;
repeating a move earns less, and getting hit drops your score.

KEYBOARD                  CONTROLLER (Xbox-style labels)
A / D  Move               Left stick
SPACE  Jump / Double jump A / South
SHIFT  Invulnerable dash  B / East
J      Light combo        X / West
K      Launcher / Air slam Y / North
ESC    Pause / Resume     Start
R      Restart to title   Back / Select
ENTER  Start / Retry      A / South (focused menu button)
M      Mute SFX
F11    Fullscreen

Try: J -> J -> K -> Jump -> J -> J -> K
Air light hits briefly suspend both you and an airborne target.
A dash can cancel an attack. There are no guns, parries or extra weapons.

LIMITATIONS
One arena, one enemy type, five waves. No save, music, rebinding, online play,
or progression. Runs restart at the title. Controller hardware and native
Windows runtime need release verification; see BUILD_STATUS.txt.
