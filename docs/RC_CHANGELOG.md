- Retains five waves, movement/double jump, dash invulnerability/cancel, ground/air combos, launcher/slam, AI and attack tokens, Style scoring, hitstop, pause/retry and victory/defeat.
- Uses already integrated player/enemy sheets, health bars and shared 12-layer Parallax2D forest; retains nearest filtering and integer presentation. No artwork or mechanics added.
- Adds explicit media inventory, rights report, public packaging gate, private QA export whitelist, embedded Windows-pack startup/resource validation, ZIP/hash verification and provenance.
- Adds installation/controls, accurate credits, limitations and draft itch.io copy.
- Fixes confirmed missing controller-A menu confirmation binding; synthetic joypad events now start/retry the game. Combat input bindings and mechanics remain intact.
- Explicitly includes script-loaded scenes, AttackData resources and global classes in selected-resource exports; startup testing caught the initial omissions before ZIP creation.

Public release remains blocked by asset rights and native Windows/hardware/manual playtesting. No automatic publication or merge.
