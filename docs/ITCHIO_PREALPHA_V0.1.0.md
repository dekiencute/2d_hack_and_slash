## Short description

A compact pixel-art 2D hack-and-slash prototype. Clear five waves, launch enemies into the air, chain attacks and vary your moves to build Style.

## Page description

Stylebreaker is a small combat pre-alpha set in one forest arena. Move, double jump and dash through enemy attacks. Chain ground strikes, launch enemies, continue combos in the air and finish with an aerial slam. Repeating the same move earns less Style; mixing attacks rewards variety.

Includes one enemy type, five waves, keyboard and Xbox-style controller mappings, synthesized sound effects, pause/retry and victory/defeat screens. No music, saves, progression, multiplayer or remapping. Some feedback and UI panels remain placeholders.

## Install and controls

Requires Windows x86_64 and an OpenGL 3.3-compatible GPU. Extract the whole ZIP and run `Stylebreaker.exe`; Godot and a separate PCK are not required. The executable is unsigned. Do not present the private QA ZIP as the public download.

| Action | Keyboard | Controller (Xbox labels) |
|---|---|---|
| Move | A / D | Left stick |
| Jump / double jump | Space | A / South |
| Dash | Shift | B / East |
| Light combo | J | X / West |
| Launcher / aerial slam | K | Y / North |
| Pause | Esc | Start |
| Restart to title | R | Back / Select |
| Start / retry | Enter | A / South on focused button |
| Mute SFX | M | — |
| Fullscreen | F11 | — |
